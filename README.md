# Store Dashboard

Консольное приложение на Python для работы с базой данных магазина с использованием SQLAlchemy и PostgreSQL.

Проект позволяет получать статистику по магазину, просматривать каталог товаров, добавлять новые товары, оформлять заказы и выполнять аналитические запросы к данным.

## Функциональность

### Основные возможности

- Подключение к PostgreSQL через переменную окружения `DATABASE_URL`
- Отчет по магазину:
  - количество пользователей;
  - количество товаров;
  - количество заказов;
- Просмотр каталога товаров с ценами и остатками;
- Отображение топ-3 покупателей по количеству заказанных товаров;
- Добавление нового товара;
- Оформление заказа;
- Проверка существования пользователя и товара;
- Проверка остатка товара на складе;
- Использование транзакций для безопасной записи данных.

### Дополнительные возможности

- Отображение товаров с низким остатком на складе;
- Расчет выручки по каждому товару;
- Поиск пользователей без заказов.

## Основные операции

### Добавление товара

Позволяет добавить новый товар в каталог.

Пользователь вводит:

- название товара;
- категорию;
- цену;
- количество на складе.

После успешного добавления товара выводится идентификатор новой записи.

Пример:

```text
Введи название продукта: Test Product
Введи название категории: Electronics
Введи цену: 19.99
Введи кол-во: 50

New product ID: 201
```

### Оформление заказа

Позволяет создать заказ по email пользователя и названию товара.

Перед созданием заказа выполняются проверки:

- существует ли пользователь;
- существует ли товар;
- достаточно ли товара на складе.

После успешного оформления заказа выводится идентификатор заказа.

Пример:

```text
Введи email клиента: user8@example.com
Введи название продукта: Vertex Water Bottle 65
Введи кол-во продукта: 2

New order ID: 30001
```

Возможные сообщения об ошибках:

```text
Клиент не найден
```

```text
Продукт не найден
```

```text
Недостаточно товара на складе
```

## Отчеты

### Store Dashboard

Выводит:

- количество пользователей;
- количество товаров;
- количество заказов;
- каталог товаров;
- топ-3 покупателей по количеству заказанных товаров.

### Low Stock Products

Отображает товары с остатком менее или равным 10 единицам.

### Product Revenue

Отображает общую выручку по каждому товару на основании оформленных заказов.

### Users Without Orders

Отображает список пользователей, не имеющих заказов.
